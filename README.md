## 🚀 Getting Started

No build tools or node modules are required! The site runs directly in any modern web browser.

### Option 1: Direct File Opening
Double-click `index.html` in your file explorer to launch the website in your default web browser.

### Option 2: Live Server (VS Code Extension)
1. Open the `Pulse-Forge` folder in Visual Studio Code.
2. Install the **Live Server** extension (by Ritwick Dey).
3. Right-click `index.html` and click **"Open with Live Server"**.
4. The site will run on `http://127.0.0.1:5500`.

### Option 3: Python Built-In HTTP Server
If Python is installed on your system, run:
```bash
python -m http.server 8000
```
Then navigate to `http://localhost:8000` in your web browser.
